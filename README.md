# 腾讯文档通用报名助手

适用于 Microsoft Edge 和 Google Chrome 的腾讯文档收集表扩展。打开收集表后，可以在扩展弹窗里预先准备答案，再立即填写或设定填写时间。默认由你核对并提交，也可以为当前任务开启自动提交。

## 安装

1. 下载并解压 GitHub 仓库源码，或将仓库克隆到本地。
2. 在 Edge 打开 `edge://extensions`，或在 Chrome 打开 `chrome://extensions`，开启「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择包含 [manifest.json](TencentForm_OneShot/manifest.json) 的 `TencentForm_OneShot` 目录。可直接加载源码。
4. 打开腾讯文档收集表。安装或重新加载扩展后，刷新已经打开的收集表页面。

扩展识别的是 `https://docs.qq.com/form/page/…` 格式的收集表页面。

## 使用

1. 在收集表标签页点击扩展图标。核对弹窗显示的表单名称和题目，再填写答案。关闭弹窗后，本次浏览器会话内仍可打开同一张表继续编辑草稿。
2. 点击「立即填写」，或按电脑本地时间选定执行时刻后点击「启动定时」。定时最多提前 7 天，等待期间请保持浏览器和原表单标签页打开，并尽量将表单页置于前台。
3. 填写完成后，在原网页核对答案。若要自动提交，启动前勾选「填完后自动提交并处理提交确认」，并在弹窗补齐识别出的必填题。若网页弹出「确认提交你的结果吗？」，扩展会尝试点击一次「确认」。是否提交成功以腾讯文档页面提示为准。
4. 如需停止待执行的任务，在原表单标签页打开扩展并点击「取消任务」。

## 支持的题型

| 题型 | 在扩展中怎么填 |
| --- | --- |
| 文本、长文本及常见原生日期和时间控件 | 在对应输入框中准备答案。 |
| 单选 | 选一个选项，也可以清除选择。 |
| 多选 | 勾选要回填的选项。选项同名时，弹窗按网页顺序标注「第 1 项」「第 2 项」等序号。 |
| 原生下拉单选 | 从下拉列表中选一项。 |
| 仅显示标题的预览题 | 可以先写草稿。选择题填写完整选项文字，多选每行一个。控件开放后建议重新识别并核对。 |

## 常见情况

| 看到的情况 | 可以怎么处理 |
| --- | --- |
| 弹窗提示打开收集表，或未识别到题目 | 检查当前标签页是否为收集表，确认表单已加载，然后刷新网页并点击「重新识别」。 |
| 某题显示「请在原网页填写」 | 在原网页完成这道题。若要让扩展填写其余题目，取消勾选自动提交，再启动填写。 |
| 填写窗口结束，部分答案未填上 | 检查题目和选项是否有变化、控件是否开放，再重新识别并核对草稿。任务通常在开始执行后等待最多约 20 秒。 |
| 弹窗显示已点击提交，或提交结果未确认 | 查看原网页是否出现成功提示、确认框或校验错误，以页面当前状态判断后续操作。 |

## 权限和数据

- `activeTab` 用于扩展弹窗读取当前标签页信息。内容脚本的注入范围由 [manifest.json](TencentForm_OneShot/manifest.json) 限定为腾讯文档收集表。
- `storage` 用于在 `chrome.storage.session` 中保存按表单区分的草稿和按标签页区分的任务。重启浏览器后需重新准备草稿和任务。
- 自动填写和提交通过当前表单页面的控件执行。勾选自动提交即允许本次任务通过腾讯文档提交所填内容。

## 开发和打包

扩展源码位于 [TencentForm_OneShot](TencentForm_OneShot/)。[技术交接文档](docs/TECHNICAL_HANDOFF.md) 记录了源码结构、草稿和任务格式、排查方法、验证清单以及 Windows 打包命令。

`dist/` 用于存放本地构建产物，`local/` 用于存放本地工作材料。两个目录均已配置为 Git 忽略。若在 GitHub 网页手动上传源码，请选择扩展源码、`docs/`、`README.md` 和 `.gitignore`。
